# Exemple de cours : la concentration molaire

La **concentration molaire** d'une espèce dissoute est la quantité de matière de cette espèce par litre de solution :

`C = n / V`

| Grandeur | Symbole | Unité |
|---|---|---|
| Concentration molaire | C | mol·L⁻¹ |
| Quantité de matière | n | mol |
| Volume de solution | V | L |

## Exercice

On dissout 0,050 mol de chlorure de sodium dans 250 mL d'eau. Quelle est la concentration de la solution ?

<details>
<summary>Voir la correction</summary>

V = 0,250 L, donc C = 0,050 / 0,250 = **0,20 mol·L⁻¹**.

</details>
